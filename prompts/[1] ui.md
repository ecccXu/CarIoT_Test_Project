# UI


> **站在产品经理和设计师的角度**，使用 HTML +CSS 设计一个仅面向 Web网页端的《车载环境传感器测试系统》产品原型(名字叫做CarTest MQTT)  
> 
> 设计需以真实产品为目标，页面结构清晰、层级合理，
> 整体视觉风格应简洁克制，偏向产品原型而非概念设计，可合理使用开源图标库来增强界面表达，
> 最终产出需能够宣接作为前端和后端开发阶段的参考依据。本项目仅需实现网页版效果，不考虑原生 App 或多端适配问题。
> 
> 在文件组织与实现方式上，
> 请创建一个目录用于存放各个页面文件，
> 每一个界面都应作为独立的 HTML 文件存在，例如 car-data.html、car-test.htmL 等。
> 使用index.html 作为唯一主入口,index.html中不直接编写所有页面的 HTML 代码，而是通过 iframe的方式嵌入上述各个独立页面，
> 并在 index页面中将所有页面同时平铺展示，用于整体原型的集中预览，而不是通过页面跳转或路由切换的方式进行展示。
